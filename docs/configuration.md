# 接收者的本地配置

这些技能不依赖整理者的学校、账号或硬盘路径。

| 场景 | 接收者需要提供或确认 |
|---|---|
| 论文阅读 | 论文文件或可访问链接；需要时说明阅读深度与输出位置 |
| 课程材料 | 当前课表、课程名、教材版本、原始材料目录和已有学习入口 |
| 作业交付 | 本次通知、数据、允许使用的工具和提交要求；封面身份只用接收者提供的信息 |
| 音视频 | 源文件或已有转写、选定平台及其可用账号；本包没有私有平台worker |
| 托福练习 | 本次题面、本人原稿、目标任务；有课程笔记则按需提供，没有也可按官方依据练习 |
| Obsidian | 本次授权的库或笔记文件；原图保留，不扫描无关笔记库 |

现有项目规则、已确认授权和本次请求优先。其他用户曾经允许的上传、归档、清空答案或定时提醒不随技能转移。读文件和本地整理不自动扩展成云端发布。

# 发给同学：论文阅读快速上手

推荐分享本页面的 GitHub 链接。可以在线看说明；要安装时下载 ZIP。仓库首页的 Code → Download ZIP 包含全部技能，`packages/paper-reading-kit.zip` 是只含论文阅读相关技能的轻量包。

## 四个入口

| 想要的结果 | 选哪个 |
|---|---|
| 看懂问题、方法、图和结果，边读边问 | **paper-reading-coach：论文精读教练** |
| 全文中英对照，段落和图表都保留 | **nature-reader：全文中英对照** |
| 留下完整的研究分析档案 | **nature-paper-card：16节精读卡** |
| 用浏览器打开中文学习页 | **paper-teaching-pages：中文讲解页** |

只想理解论文，先用第一个。它可以单独使用，不要求写16节报告。其他三个用于明确的交付请求。

## 安装与依赖

解压轻量包，把 `skills/` 下要用的完整技能文件夹复制到当前智能体的技能目录；Codex 常见为 `~/.codex/skills/`。保留各技能的许可与来源文件；已有同名技能先备份。不要把整个 ZIP 路径当成一个技能目录。

带读本身是一套指令；读取PDF、查看图像或检索链接需要当前智能体具备相应工具。精读卡、公式检查及网页校验的辅助脚本需要 Python 3.10 或更新版本；PDF准备脚本可使用 PyMuPDF。按具体输入安装必要依赖，不需要为纯文本阅读先搭建完整科研环境。

不支持文件、图像或脚本的普通聊天客户端，只能使用其实际支持的部分；上传一个 SKILL.md 不等于取得全部工具能力。

## 可以直接复制的请求

**带读：**

```text
请用 $paper-reading-coach 带我读附件论文。
先讲它解决什么问题，再解释专业词和符号，用原图讲核心方法。
每次一个重点；作者结论、教学比喻和你的推断请分清。
```

**只解释一个图：**

```text
请用 $paper-reading-coach 解释 Fig. 2：看哪里、怎样沿箭头读、
每个模块的输入输出是什么，以及图本身支持什么结论。不要生成全文翻译。
```

**全文中英对照：**

```text
请用 $nature-reader 把附件全文做成中英对照 Markdown。
保留段落、图表和公式，记录真实来源位置；缺页或识别不稳的地方明确标出。
```

**精读卡：**

```text
请用 $nature-paper-card 生成中文16节精读卡。
重点核对方法模块、实验条件、结论边界与可验证研究想法。
```

没有PDF时可以先给 DOI、arXiv 或正式链接。取得不了全文时，技能应只解释可见内容并说清范围，不编造实验。原图和论文全文不随技能包分发，需要由读者合法提供或访问。

## 这次优化

- 新增“论文精读教练”，通用带读不再默认触发全文翻译。
- 明确区分局部提问、片段对照、全文对照、研究卡和网页。
- 术语和符号先解释，方法按依赖关系讲，训练和预测分开。
- 原图必须实际查看后讲解；辅助示意和教学数字明确标记。
- 实验数字保留条件，区分百分点与相对增幅，参数少与运行快分开。
- HTML与缺页材料保持结构定位，不把未知页码填成第1页。
- 两个社区阅读包补齐共享术语文件，独立解压安装即可读取。

验证包括结构与链接检查、公式验证器自测、7个来源页码回归测试，以及三种局部阅读请求的独立行为检查。它们不等于对任意论文结论的自动科学认证。

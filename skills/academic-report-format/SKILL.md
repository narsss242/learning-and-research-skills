# 学术报告排版

这份工作流沉淀了个人报告排版习惯，供没有指定模板时参考。使用时读取自包含的[排版规范](references/format-spec.md)，不必再询问原提示词路径。用户当次要求、课程任务书和明确指定的模板优先；本技能是没有更具体要求时的报告默认规范。

## 工作方式

- 配合环境已有的文档/PDF技能；若环境提供依赖发现工具则使用它。本技能补充个人版式，不能替代相应技能的导出与视觉核验要求。
- 修改报告前保留副本，并记录数据和内容基线。排版不得默改计算路线、单位、小数位、数据点、来源或结论；重新编号时同步更新文内引用。
- 将规范应用到实际段落、字符和表格属性；清除会覆盖字体的主题设置、默认装饰线、残留表格底色和边框。
- 总结表用三线表，按语义分配列宽。数字和短符号居中，长句左对齐，垂直居中。复杂计算附表以可读性为先，允许必要的分组线。
- 默认整表同页，用段落保持关系绑定表题和全部表行，不能仅设置“行内不拆分”。若表确实高于一页，先调整列宽、间距和附表字号，再按自然记录组拆成明确标识的续表；不删点、不压到难以阅读。
- 公式用原生可编辑 OMML 或交付格式支持的原生数学。分式、根式和上下标使用真实结构；变量斜体，函数名、描述性下标、数字及单位正体。不能把斜线文本装进数学容器就称为专业分式。
- 图与图题、表与表题保持同页。长图注可采用居中的短标题和紧邻下方的说明；不要靠缩小整幅图或整段粗斜体挤版。
- 正文页码从首个正文部分的 1 开始；有 Abstract 时从 Abstract 起，无摘要时从 Introduction 起，不为套版式自动增加摘要；封面和目录不计入正文页码，目录显示正文页码。参考文献默认 Harvard 作者—年份制，列实际使用的正式来源；课件不列入 References，用户提供的标准、教材、论文不因提供方式而排除。正文过程与结果充分时可不设附录。具体判据见排版规范。
- 从最终 Word 导出对应 PDF，渲染并查看全部页面，核对表格、公式、编号引用和分页。Windows 缺 LibreOffice 时，可用本机 Word COM 导出 PDF，再用 Poppler 等渲染；不能因此跳过视觉检查。

- 数值展示与内部计算精度分开；按已确认的精度统一正文与结果表，保留计算底稿。报告精简、算例安排和数值展示遵从排版规范中的对应条目。

## 交付

提供真实可打开的文件链接，简述实际应用的规范及必要例外。只在新出现的信息确实缺失时询问，不因本技能重复请求已给出的格式或授权。可自动用于相关报告任务，也可明确调用 `$academic-report-format`。

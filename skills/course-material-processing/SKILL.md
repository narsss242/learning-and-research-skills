# 课程材料处理

## 先确定课程和来源

- 先读当前课程的 AGENTS.md、学习入口、资料清单及处理记录；复用已有目录，保护手写笔记、答案与历史整理。
- 课程正式名称以用户课表为准，本地课程目录、学习入口和得到大脑知识库统一用该名称；笔记自动标题只用于主题，不据此另起课程名称。查看课表核对课程时间，记录课表路径、工作表、周次/日期、星期和节次，结合正文主题和实际录音时间判断归属。上传时间、创建时间不等于上课时间；调课、补课、同学上传、跨午夜记录须单独说明。课表冲突时保留待核对，不能仅凭时段归类。
- 本机已知课表与课程样例见 [references/local-workflows.md](references/local-workflows.md)。先核验文件存在及适用学期，不把旧课表永久套用。
- 建候选清单：来源 ID、标题、创建时间、实际课堂时间及依据、标签、内容主题、录音时长、判定及理由。去重以 ID/内容指纹为准；同堂的不同记录可以互补，不擅自删除。

## 录音与得到大脑

1. **任何得到大脑操作前**按 [课程资料配置](references/local-workflows.md) 找到本次用户的既有流程与授权来源；核验当前接口或导出能力，不使用其他人的会话或课程脚本。
2. 多关键词检索并按课表时段补查，读取候选完整 content 后再决定归属。仅检索课程全名容易漏掉以章节、实验、英文主题命名的记录。
   - 对“AI链接笔记”检查其附件来源，可能只是同学课堂分享的二次摘要。沿用户已有分享链接读取可访问的原笔记和 share original，分别记录来源课堂ID、分享ID、本地收藏ID与日期；授权课程归档包含保存这些课程来源，不扩展到分享者的其他笔记。
   - 列表分页依据服务端 has_more/has_next 与末条ID推进；服务端可能忽略请求page_size而只返回20条，不能仅按返回数量少于请求数便停止。
3. 原始导出保存完整 content；录音同时取 `/notes/{id}/original` 的逐句转写，需要时取 `show_opt_asr=true` 的平台优化稿。逐句 JSON、带时间戳 Markdown、平台总结及本地校正版分开，保留全部句段、说话人和毫秒时间。不用摘要冒充逐字原稿；无转写或失败的文件明确记录原因。
4. 校正只改证据充分的术语/符号，保留前后对照；未回听则标“未听校”。作业、截止时间、考试范围记录来源 ID 和时间戳，区分平台推断、学生说法、教师可定位表述和回听确认。
5. 仅当本次用户明确要求放入得到大脑知识库且目标清楚时，将确认相关的原笔记加入指定的现有知识库。先核验知识库名称、topic_id、根目录 directory_id 和已有成员，只补入缺项；不重复询问已授权的归档。目标含混或无对应库时，继续本地处理并仅就目标提出必要问题，不擅自创建同名库、改原笔记、分享或归档其他课程。
6. 入库后分页回读核对来源 ID。请求结果不确定时先读成员再重试。导出到课程目录和既有 Obsidian 课程位置，保留来源/日期/哈希/数量/正文长度/句数及缺失项；不覆盖人工整理。
7. 令牌、刷新令牌和设备标识只在本机进程内使用，不输出或落盘。带签名的附件链接不复制进公开日志；需要时本地化并记录替换，不把改写后的文件称为逐字节原文。认证失效时按已验证流程刷新一次；明确失败才请求用户重新登录。

## 书籍与课件

- 先读 [references/book-workflow.md](references/book-workflow.md)，迁移机械精度设计的处理方法，不能迁移它的章号、公式、考试重点或特定自动清空作答规则。
- 确认主教材的书名、作者、版本和目录，建立教材页码—PDF页序—课件—课堂记录映射；旧版、辅源独立标明。
- 在授权章节范围内按“五件套”完成：可搜索分章 PDF、忠实全文 Markdown、综合学习 Markdown、三栏学习 HTML、按来源分节的题目 Markdown。扫描书先保留原页，再 OCR；核对公式、表格、图号与数值，不能用摘要替代全文。未找到主教材时先完成录音/课件路线，明确材料缺口，不凭相似书补全文。
- HTML 三栏为讲解/需要记忆的内容/抽查。没有考试依据的必背项标为学习建议。题目分为书上题、课件题和自测题，答案可折叠；不虚构用户错题或掌握状态。
- 图示先查看用户原图、附页码，按“看哪里→如何读→概念→应用”讲解，一次一两张；辅助示意明确标注。首次解释专业名词、符号/上下标及单位，多步计算必要时用展示分支和汇合的方块流程图。

## 交付和检查

- 提供一个“从这里学”入口、按课堂时间或章节的索引、来源映射和实际处理记录，记录已完成与仍缺失内容。
- 验证正文未截断、逐句数量匹配、知识库成员回读一致、Markdown/HTML本地链接有效；PDF/HTML涉及图表或排版时实际渲染检查。同步副本核对哈希。
- 交付时报告真实数量、知识库归档结果、入口位置及必要限制。无音频听校、无主教材、课程时间仅推断等情况如实说明。

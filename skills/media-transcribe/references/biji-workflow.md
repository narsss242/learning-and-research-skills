使用当前用户自己的账号和本次授权范围。先读取其已有操作流程，复用可验证的现有结果与登录；账号不明确或需要扫码、验证码时请用户完成实际认证步骤。

公开包不含私有 API 客户端、会话提取器、令牌或设备配置。优先使用用户已提供且核验过的实现、官方导出或可用的应用操作能力。无法取得完整正文时明确说明，不以平台摘要冒充原稿。

新音视频任务先核对文件、时长和服务可用性；服务收费或额度变化按当前界面核实，不自行购买或充值。仅在任务授权覆盖上传时上传到指定平台。

取回完整 content 与平台提供的逐句原稿，保留句段、原始时间和发言人字段；平台优化稿、智能总结和本地校正版分别保存。记录覆盖范围、缺失与实际校对方式。

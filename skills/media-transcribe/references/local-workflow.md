# 用户明确选择的备用转写服务

只有用户明确选择通义听悟等备用服务时才使用。此分享包不附带本机私有 worker 或其认证配置；不能直接运行不存在的历史脚本。

使用当前环境中可用且有授权的连接器或客户端，先检查服务限制、时长、发言人数和已有任务；提交后记录任务标识，结果不明时查询而非重复提交。密钥用服务推荐的运行时认证方式，不写进任务清单或技能。

保留原稿、逐句时间和平台实际返回的发言人；字幕OCR、另一平台转写和人工回听是不同校验来源。只进行了文字核对时不能称逐句回听。

本技能不附带声学分离模型。需要该能力时先说明可用工具与成本，由用户的当前要求决定；不能把目录存在当成环境可运行。

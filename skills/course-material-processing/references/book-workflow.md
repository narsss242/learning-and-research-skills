# 教材处理与五件套学习资料

先读取当前课程既有的学习体系总览、材料映射与目录约定。下面是可迁移方法，不附带任何具体课程的原书或私人笔记。

## 保留的方法

1. 先确认版本和章界。页码映射至少含PDF物理页与书上印刷页；课件/作业章号不一定等于教材章号，以内容映射。
2. 保真材料在 `其他材料/教材/` 或课程已有 `资料/` 内：原书、分章可搜索PDF、全文MD和原图。扫描OCR需保留页界及图表出处，对无法辨认项显式标注，不补造正文。
3. 日常入口使用课程现有布局；新建时可用 `从这里学.md`、`第N章/学习.html`、`第N章/笔记.md`、`第N章/题目.md`。综合学习稿可用笔记.md承载，明确与全文MD区别。
4. 五件套：分章PDF、忠实全文MD、综合学习MD、三栏HTML、分源题目MD。不能只有五个空文件，未完成项记录真实状态。
5. 讲解联系原书、课件、课堂录音，公式与表值可追溯；无课堂材料则标“教材自学，未取得课堂记录”，不能由没有录音推断老师没讲。
6. 用户自建笔记/错题本通常每课程各一份、按章组织；只在确有内容时写入，避免生成一堆空壳。自测题和实际错题区分；不从其他项目继承清空作答记录的授权。

## 验收

核对章界与页数、抽取全文覆盖、重点公式/表格原图、版本隔离、题目来源及答案链接。学习页实际打开检查图/公式/折叠答案；来源缺失或未校核的数值明确标注。不要以文件数量代替内容和学习效果验收。
